# 🛒 Next Commerce

A modern full-stack ecommerce application built with Next.js, MongoDB, and Mongoose.

---

## 🚀 Tech Stack

- Next.js
- React
- MongoDB
- Mongoose
- Tailwind CSS
- NextAuth / Better Auth (planned)
- Cloudinary (planned)
- Stripe SSLCommerz (planned)

---

## 📦 Features

### User Features

- User authentication
- Browse products
- Product details page
- Add to cart
- Checkout system
- Order tracking

### Admin Features

- Admin dashboard
- Add/Edit/Delete products
- Manage orders
- Manage users

---

## 🛠️ Installation

```bash
git clone <your_repo_url>

cd project-name

npm install

npm run dev
```
